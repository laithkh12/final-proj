# TeamFlow Frontend

Next.js App Router client for the TeamFlow API.

## Setup

```bash
cp .env.example .env.local
npm install
npm run dev
```

App: http://localhost:3000

Set `NEXT_PUBLIC_API_URL` to your backend (default `http://localhost:5000/api`).
